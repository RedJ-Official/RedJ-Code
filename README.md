# RedJ Code

RedJ Code is a free and open source code editor for Windows.

RedJ Code is based on a [fork](https://github.com/RedJ-Official/ImprovedFastColoredTextBox) of Pavel Torgashov's [FastColoredTextBox](https://github.com/PavelTorgashov/FastColoredTextBox).

### Download

You can download the relase version on our official Website - [www.redj.me](https://www.redj.me/code/).

### Features

RedJ Code currently supports the following features:

#### File Commands

- Create/Open/Save Files
- Recently used files list
- Export files as formatted RTF or HTML
- Print files
- View file properties and hashes / rename file
- Change file encoding
- Multiple document support

#### Supported Languages

- Plain Text
- C#
- Batch (CMD) files
- HTML
- Java
- JavaScript
- JSON
- Lua
- PHP
- Python
- SQL (SQL Server and MySQL)
- Visual Basic
- XML
- More to be added in future updates...

#### Editing Commands

- Multi-level Undo/Redo
- Cut/Copy/Paste
- Copy as RTF/HTML
- Select All
- Find and Replace (with RegEx support)
- Add/Remove line prefix
- Go to line
- Change Indent (Auto-indent for supported languages)
- Comment/Uncomment for supported languages
- Move lines up or down
- Autocomplete for supported languages
- Special text conversion: Base64, URL and RegExp encode/decode
- Chance case (upper, lower, title, sentence, invert, random)
- Insert date and time+
- Insert predefined code snippeds for supported languages

#### Advanced Features

- Syntax highlighting for supported languages
- Folding blocks with folding lines for supported languages
- Word wrapping with auto-indent
- Highlighting for current line and word
- Auto-indent while typing
- Auto bracket completion for supported languages
- Virtual Space
- Drag-Drop support
- Document Map
- Ruler
- Bookmarks
- Macros

#### Additional Tools

- built-in Terminal (cmd)
- built-in File Explorer
- MergeDiff tool
- WYSIWYG HTML Document Editor (deprecated - use [SiteMaker](https://www.redj.me/sitemaker/) instead)
- GUID generator

New Features will be added in future updates.
